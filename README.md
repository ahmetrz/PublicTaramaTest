# PublicTaramaTest

Bu depo yalnızca kontrollü ESG testlerine ait sentetik belgeleri barındırır. Dosyalardaki şirket etiketleri test yönlendirmesi içindir; içerikler gerçek şirket beyanı, raporu veya kanıtı değildir.

Test verileri ücretli sağlayıcı çağrısı yapmaz. `T03` içerikleri A/B sürümleridir; farklı dosya yolları aynı URL'de sürüm değişimini kanıtlamaz. `T19` için statik barındırma yalnızca mevcut ve bulunmayan sayfa kontrollerine uygundur; 401/403/429/5xx ve gecikme uçları sunamaz.

GitHub Pages etkinleştirildiğinde test adresi: https://ahmetrz.github.io/PublicTaramaTest/
